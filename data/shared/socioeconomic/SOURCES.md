# Socioeconomic layer: sources and method

Generated by `fetch_socioeconomic.py` (stdlib only). Outputs: `alviso.json`, `novva.json`. Each indicator carries
`name, value, unit, plain_english, rag, rag_rule, source, method (api|cited|assumed), date, scored`.
Overall RAG rule: RED if the environmental-justice indicator is RED or two or more scored indicators are RED; GREEN if none RED and at most one AMBER; otherwise AMBER.

Sites: Alviso / North San Jose = tract 06085504602 (Santa Clara County, 06085). NOVVA Colorado Springs = tract 08041007205 (El Paso County, 08041). Tracts resolved from the coordinates with the FCC Census Block API (https://geo.fcc.gov/api/census/block/find).

| Indicator | Source | Method |
|---|---|---|
| Population, median household income, poverty, unemployment, % renters, median age | ACS 5-year 2020-2024 Data Profiles DP03/DP04/DP05 (DP05_0001E, DP05_0018E, DP03_0062E, DP03_0128PE, DP03_0009PE, DP04_0047PE). api.census.gov now answers "Missing Key" without a key, so the script reads the same tables from the keyless data.census.gov table API (`https://data.census.gov/api/access/data/table?id=ACSDP5Y2024.DP03&g=1400000US06085504602`). That endpoint sometimes returns an empty 204; the script retries. | api |
| Commercial / industrial retail electricity price, CA and CO | EIA retail-sales API v2, state annual average, latest year (2025). Key read at runtime from `EIA_API_KEY` (or the file named by `EIA_ENV_FILE`); never written to output. | api |
| Energy burden (low-income households, <=80% area median income) | DOE/NREL LEAD Tool 2022 update, OpenEI submission 6219 (https://data.openei.org/submissions/6219; files `CA-2022-LEAD-data.zip`, `CO-2022-LEAD-data.zip`, ~1 GB and 130 MB). Computed here as total energy cost (electric + gas + other fuel) / total income over AMI-bin rows, county level; tract value in `note`. The LEAD web tool shows rounded figures, so small differences are expected. The zips are not committed; pass `--lead-dir`. | cited (published dataset, computed) |
| Environmental-justice burden, Alviso | OEHHA CalEnviroScreen 4.0, tract percentile (`CIscoreP`) from the CalEPA/OEHHA ArcGIS layer `CES4_Percentile`. | api |
| Environmental-justice burden, Colorado | CDPHE / Colorado State University Colorado EnviroScreen v2.0 census-tract layer, overall percentile (`ES_S_`). Used instead of EPA EJScreen, which was taken offline in 2025 (no archive pulled). | api |
| Permanent jobs per 100 MW (20-40) | Hamm Institute workforce forecast (Nov 2025) and Latitude Media benchmark, both seen only through a secondary roundup, not re-verified against the originals. | cited (estimate) |
| Peak construction workers per 100 MW (70-200) | Chmura Economics article citing an unnamed workforce study (0.7-2.0 workers/MW); Apollo Technical 2026 tracker gives ~4.1/MW at peak. Underlying study not located. | cited (estimate, unscored) |
| Property tax per 100 MW per year | Assumed: $1.0B taxable value per 100 MW (illustrative, no source) times a rate. CA ~1.15% (1% Prop 13 base + voter-approved debt, San Jose Unified; Santa Clara County Assessor). CO 25% non-residential assessment rate (El Paso County Assessor, 2026) times ~67 mills (unverified aggregator figure) = ~1.7%. Ignores server depreciation, Prop 13 assessed-value limits and abatements, so treat as an upper-bound order of magnitude. | assumed |

## Not done

- Land / industrial context indicator: no verified source was obtained in the time box, so it is omitted rather than invented.
- Electricity price is a state average, not the serving utility's tariff (PG&E / SVP / Colorado Springs Utilities will differ).
- ACS tract estimates have wide margins of error for small tracts (Alviso population ~1,500); margins are not in the JSON.
- The data-center jobs and tax rows are the same shape for both sites and do not make the sites differ except through the tax rate.
